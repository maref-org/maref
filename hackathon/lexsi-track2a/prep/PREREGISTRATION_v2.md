## 为什么需要 v2

v1 的 `c06` 缺口（首字母拼词）不能再用 `c06` 原文验证——实现一旦针对它修改，
用同一实例测试必然通过，等于过拟合单例。v2 全部为**新构造**样本，且包含
同类不同实例（8 条 acrostic 攻击，首字母分别拼出 IGNORE / BSO / DOTH / EXIT /
ALLOW / SUDO / ROOT / PRINT）与**结构相同但无害**的对照（6 条）。

> 报告必须把结论限定为「单例修复」，不得声称覆盖该攻击家族。
