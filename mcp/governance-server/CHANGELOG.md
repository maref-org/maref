# Changelog

## 0.1.0 (2026-07-18)

- Initial release
- MCP Governance Proxy Server wrapping any MCP server with MAREF guardrails
- Three governance modes: enforcing, advisory, logging
- Decision caching with configurable TTLs
- Fail-closed / fail-open behavior
- Tool classification (write/execute/read)
- Built-in `maref_governance_status` introspection tool
