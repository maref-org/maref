# MAREF 小红书风格图文内容生成 Skill

> **版本**: v1.0
> **适用**: 小红书/即刻/公众号等图文平台
> **风格来源**: 手绘信息图叙事体系（炒股知识类爆款结构）
> **映射目标**: MAREF 智能体治理框架的技术叙事
> **源文档**: `maref_visual_content_skill.md` @ 23-开源生态策略/

---

## 一、视觉风格规范

### 1.1 整体调性
- **风格关键词**: 手绘插画 / 信息图解 / 轻科普 / 有温度的技术叙事
- **情绪基调**: 专业但不冰冷，权威但不居高临下
- **色彩体系**:
  - 主色：暖橙/砖红 `#E86A3C`
  - 辅色：深蓝 `#2E5090`
  - 点缀：暖黄 `#F5C842`
  - 背景：米白/浅灰 `#F8F6F0`
- **字体层级**: 大标题24-32pt / 阶段标题18-20pt / 正文14-16pt / 标注等宽

### 1.2 插画元素库
- **人物**: 简笔卡通人（思考、操作、监控、阅读）
- **图标隐喻**: 监控→放大镜/雷达、治理→盾牌/锁、风险→温度计/警报、成长→树根/阶梯
- **装饰线**: 波浪线、虚线箭头、手绘边框、胶带贴纸效果

### 1.3 版面布局
- 信息密度: 3-4 核心模块/页
- 视觉动线: Z字形或环形时间线
- 留白: 模块间 15-20%

## 二、核心叙事结构

### 2.1 叙事公式（炒股 → Agent 治理映射）

**原结构**: 时间线叙事（早盘→盘中→收盘→长期）
**MAREF 映射**: 部署前→运行中→事后审计→长期架构

### 2.2 标题生成公式

| 类型 | 公式 | MAREF 示例 |
|------|------|------------|
| 揭秘型 | 真正[角色]每天到底在干啥 | 真正搞Agent治理的人，每天到底在干啥 |
| 真相型 | [数字]%[群体][动作]真相 | 90%的Agent翻车，不是技术问题 |
| 对比型 | 别沉迷[短期]，[长期]才是根本 | 别沉迷修Bug，夯实治理层才是根本 |
| 警告型 | 不[动作]=[严重后果] | 不复盘=当天部署全白费 |
| 清单型 | [数字]个[对象]必须[动作] | 3个核心Agent必须全程盯紧 |

## 四、生成提示词模板

### 4.1 系统提示词

```
你是一位精通Agent治理的技术插画内容策划师。你的任务是为MAREF生成小红书
风格的手绘信息图文案。

MAREF定位：开源多智能体治理框架，"智能体，有规-有矩"。

输出要求：
1. 严格遵循"时间线叙事+模块化信息"结构
2. 每页3-4个模块，每个1个标题+2-3行说明+1个图标建议
3. 语言：专业但亲切，"懂技术的朋友画图给你讲"
4. 必须包含具体数字或checklist
5. 使用第二人称"你"或"我们"
6. 每页底部要有1个"真心话/金句"区域
7. 为每个模块提供【插画建议】

禁止：学术化堆砌、纯文字无视觉元素、企业白皮书风格
```

### 4.2 分场景模板

**场景A: Agent日常治理流程**（5页套装，从"部署前→运行中→审计→长期"）
**场景B: 单页爆款**（1页，3-4模块 + 底部金句）

完整模板见源文档 §4.2。

## 六、质量检查清单

- [ ] 每页不超过4个主模块，每模块不超过3个要点
- [ ] 标题3秒读完，正文10秒扫完
- [ ] 类比准确不牵强
- [ ] 至少出现1次"有规-有矩"或治理关键词
- [ ] 至少1组具体数字或结构化清单
- [ ] 有1个情绪触发点（真相/坑/境界）
- [ ] 有明确的行动号召
- [ ] 图标建议可在常见手绘库中找到
