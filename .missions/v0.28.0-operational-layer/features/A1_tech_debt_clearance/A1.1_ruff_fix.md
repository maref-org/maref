## 🎯 目标

1. 执行 Ruff 自动修复，修复 1772 个可自动修复的问题
2. 手动修复剩余的 220 个问题（主要是 E/F/S 级问题）
3. 实现 `ruff check src/` 返回 0 errors
4. 保持代码功能不变，只进行格式化和代码质量改进

## 🛠️ 实施步骤

### 步骤 1: 执行自动修复
```bash
# 1.1 执行安全修复
ruff check src/ --fix

# 1.2 执行不安全修复（如果有）
ruff check src/ --fix --unsafe-fixes

# 1.3 验证修复结果
ruff check src/ --statistics
# 目标: 将 1772 个可自动修复的问题清零
```

### 步骤 2: 手动修复剩余问题
```bash
# 2.1 查看剩余问题详情
ruff check src/ --statistics --output-format=full

# 2.2 按类别查看问题
# E/F 级问题 (错误级别的)
ruff check src/ --select=E,F --statistics

# S 级问题 (安全相关的)
ruff check src/ --select=S --statistics

# 2.3 逐个修复或批量修复
# 常见需要手动修复的问题:
# - F401 (unused-import)
# - F841 (unused-variable)
# - E402 (module-import-not-at-top-of-file)
# - E741 (ambiguous-variable-name)
```

### 步骤 3: 常见问题修复指南

#### 3.1 未使用的导入 (F401)
```python
# 修复前
import os
import sys  # 未使用
from typing import List, Dict

# 修复后
import os
from typing import List
```

#### 3.2 未使用的变量 (F841)
```python
# 修复前
def process_data(data):
    result = transform(data)  # 未使用
    return data

# 修复后
def process_data(data):
    data = transform(data)
    return data
```

#### 3.3 导入不在文件顶部 (E402)
```python
# 修复前
print("Starting...")
import pandas as pd  # 错误位置

# 修复后
import pandas as pd
print("Starting...")
```

#### 3.4 模糊的变量名 (E741)
```python
# 修复前
def calculate(l, I):  # 模糊的变量名
    return l * I

# 修复后
def calculate(length, width):
    return length * width
```
