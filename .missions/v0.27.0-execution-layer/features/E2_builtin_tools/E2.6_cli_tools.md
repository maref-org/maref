# E2.6: maref tools CLI

## Description
CLI subcommand group for discovering, installing, and configuring built-in MCP tools.

## Commands
- `maref tools discover` — list all registered built-in tools
- `maref tools install <name>` — register/install a tool, returns config
- `maref tools list` — list installed tools with status
- `maref tools info <name>` — show detailed info about a tool
- `maref tools policy <name>` — show/export policy mapping for a tool

## Dependencies
- E2.1, E2.2, E2.3, E2.4, E2.5
