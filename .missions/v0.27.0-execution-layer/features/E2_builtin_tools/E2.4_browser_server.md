# E2.4: Browser MCP Server

## Description
Built-in MCP server for web page operations with domain whitelist. Supports page fetching, screenshot, HTML extraction, and link discovery.

## Tools
- `browser_open(url)` → page text content
- `browser_screenshot(url)` → base64 PNG
- `browser_get_html(url)` → raw HTML
- `browser_get_links(url, filter_domain)` → link list

## Security
- DomainWhitelist: only allows requests to predefined domains
- Read-only operations (no form submission, no JS execution)
- URL validation (rejects IP-based URLs, blocks internal networks)
- User-agent spoofing
- Max content size for page bodies

## Dependencies
- E1.5 (policy mapping for governance integration)
