# E2.5: Email MCP Server

## Description
Built-in MCP server for email operations via SMTP/IMAP with recipient whitelist and sensitive word filtering.

## Tools
- `email_send(to, subject, body, attachments)` → message_id
- `email_list(folder, max_count)` → email summaries
- `email_read(message_id)` → full email detail
- `email_search(query, folder)` → matching message IDs

## Security
- RecipientWhitelist: emails can only be sent to approved addresses/domains
- SensitiveWordFilter: blocks sending emails containing predefined sensitive patterns
- Read-only operations by default (list, read, search)
- Write operation (send) requires explicit write mode

## Dependencies
- E1.5 (policy mapping for governance integration)
