# E2.1: File MCP Server

## Description
Built-in MCP server providing file system operations with path sandbox security. Supports read, write, list, delete, copy, move, and info operations.

## Tools
- `read_file(path, encoding)` → content
- `write_file(path, content, encoding)` → success/error
- `list_directory(path, pattern)` → files/dirs listing
- `delete_file(path)` → success/error
- `copy_file(source, destination)` → success/error
- `move_file(source, destination)` → success/error
- `get_file_info(path)` → stats dict

## Security
- PathSandbox: validates paths against allowed base directories (whitelist)
- Blocks path traversal attacks (e.g., `../../../etc/passwd`)
- File size limits for reads
- Write operations restricted to sandbox directories

## Dependencies
- E1.5 (policy mapping for governance integration)
