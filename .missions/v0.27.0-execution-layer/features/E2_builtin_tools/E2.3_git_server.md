# E2.3: Git MCP Server

## Description
Built-in MCP server for Git operations with repository whitelist and read-only/read-write mode support.

## Tools
- `git_status(path)` → working tree status
- `git_log(path, max_count, branch)` → commit history
- `git_diff(path, target, base)` → diff output
- `git_branch(path)` → branch list
- `git_commit(path, message, files)` → new commit hash (write mode)
- `git_push(path, remote, branch)` → push result (write mode)

## Security
- RepoWhitelist: only allows operations on predefined repo paths
- WriteMode gate: destructive operations (commit, push, reset) require write mode enabled
- Read-only mode by default

## Dependencies
- E1.5 (policy mapping for governance integration)
