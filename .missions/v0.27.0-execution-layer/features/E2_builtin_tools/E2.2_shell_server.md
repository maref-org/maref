# E2.2: Shell MCP Server

## Description
Built-in MCP server for executing shell commands with strict security controls. Supports command whitelist, timeout, output size limits.

## Tools
- `run_command(command, args, timeout, cwd)` → stdout, stderr, exit_code
- `get_shell_help()` → list of allowed commands

## Security
- CommandWhitelist: only allows predefined safe commands (e.g., ls, cat, head, tail, wc, grep, find, echo, date, pwd, which, whoami)
- Timeout: commands killed after timeout (default 30s, max 300s)
- Output size limit: max 1MB stdout/stderr
- Blocks shell metacharacters in args (;, |, &&, ||, $, `, etc.)
- Blocks commands with dangerous patterns (rm -rf, dd, :(){ :|:& };:, etc.)

## Dependencies
- E1.5 (policy mapping for governance integration)
