# E1.3: Audit Log HMAC Signature Integration

## Description
Each MCP governance decision generates HMAC-SHA256 signed audit entries. Provide audit log export (JSON/Syslog), batch verification, and audit trail integrity checks.

## Assertions
- E1.3-A1: 每个 MCP 调用生成审计条目，HMAC-SHA256 签名

## Architecture Changes
1. `MCPGovernance.export_audit_log(format)` — supports "json" and "syslog" formats
2. `MCPGovernance.verify_audit_integrity()` — walks entire audit log and verifies HMAC signatures
3. `MCPGovernance.get_audit_entry(index)` — retrieve single entry
4. `MCPGovernance.clear_audit_log()` — clear audit log (returns count of cleared entries)

## Dependencies
- E1.1 (base HMAC signing)
- HMAC secret key in mcp_governance.py
