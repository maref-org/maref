# E1.1 — MCP Client → 策略决策树集成

## 描述
改造 `mcp_client.py`，每次工具调用前过治理层（策略决策树 + 断路器 + HMAC 审计 + HITL）。

## 架构变更

```
改造前:  MCPClient.call_tool() → transport.send_tool_call()
改造后:  MCPClient.call_tool() → MCPGovernance.evaluate() → transport.send_tool_call()
                                    ├── MCPPolicyEngine (allow/deny/ask_user)
                                    ├── CircuitBreaker (depth/oscillation/failures)
                                    ├── AuditLog (HMAC-SHA256 signed)
                                    └── HITLRouter (high-risk operations)
```
