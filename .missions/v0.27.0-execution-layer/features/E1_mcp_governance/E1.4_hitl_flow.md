# E1.4: HITL Flow Integration

## Description
Full HITL (Human-in-the-Loop) integration for MCP governance. High-risk tool calls trigger HITL events, status can be polled, events can be listed/filtered, and auto-approve timeouts are handled.

## Assertions
- E1.4-A1: 高危 MCP 调用触发 HITL，用户确认后放行

## Architecture Changes
1. `MCPGovernance.get_hitl_events(status)` — filter HITL events by status
2. `MCPGovernance.check_hitl_timeouts()` — auto-approve expired P1 events
3. `MCPGovernance.get_hitl_event(event_id)` — get single event details

## Dependencies
- E1.1 (base HITL integration)
- HITLRouter in hitl.py
