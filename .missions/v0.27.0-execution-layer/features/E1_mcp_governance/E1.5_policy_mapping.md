# E1.5: Policy Decision Tree → MCP Authorization Mapping Table

## Description
Create a YAML-configurable mapping table that maps tool names/patterns to policy rules. Supports loading from YAML files, in-memory mapping, and dynamic rule-to-tool association.

## Assertions
- E1.5-A1: 可配置的 YAML 映射：工具 → 策略规则

## Architecture Changes
1. `MCPPolicyMapping` — YAML-loadable mapping from tool patterns to rule IDs
2. `MCPMappedPolicyEngine` — extends MCPPolicyEngine with mapping-based rule selection
3. `DefaultPolicyMapping` — default YAML mapping string

## Dependencies
- E1.1 (policy engine)
- pyyaml (already in pyproject.toml)
