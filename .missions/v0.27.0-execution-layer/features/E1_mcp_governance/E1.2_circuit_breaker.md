# E1.2: Circuit Breaker Integration into MCP Calls

## Description
Enhance MCP tool calls with per-tool circuit breaker monitoring. Track latency, error rates, and failure counts per tool. Trip the circuit breaker when thresholds are exceeded.

## Assertions
- E1.2-A1: MCP 调用触发熔断逻辑，超时/错误率检测

## Architecture Changes
1. `MCPToolCallStats` — dataclass for per-tool metrics (call_count, error_count, total_latency, max_latency)
2. `MCPCircuitBreakerMonitor` — tracks per-tool stats, provides threshold-based trip queries
3. `MCPGovernance.cb_monitor` — integrates CB monitor into governance pipeline (pre-check before policy evaluation)
4. `MCPClient.call_tool()` — checks CB state before calling, tracks latency and records to CB monitor

## Dependencies
- E1.1 (base governance pipeline)
- `CircuitBreaker` in governance module
