# E3.5 — Scheduler

## 描述
Cron 表达式解析与事件驱动调度器，支持定时任务和事件触发。

## 核心 API
- `Scheduler(task_queue: TaskQueue)` — 初始化
- `add_cron_job(name: str, cron_expr: str, task_template: Task) -> str` — 添加 Cron 任务
- `remove_job(job_id: str) -> bool` — 移除任务
- `list_jobs() -> list[CronJob]` — 列出所有任务
- `get_job(job_id: str) -> Optional[CronJob]` — 获取任务详情
- `register_event(event_type: str, handler: Callable) -> str` — 注册事件处理器
- `trigger_event(event_type: str, data: dict) -> bool` — 触发事件
- `start() / stop()` — 启动/停止调度器
- `get_next_run(job_id: str) -> Optional[str]` — 获取下次执行时间

## CronJob 数据
- `id: str` — UUID
- `name: str` — 任务名称
- `cron_expression: str` — Cron 表达式
- `task_template: Task` — 任务模板
- `enabled: bool` — 是否启用
- `last_run / next_run: Optional[str]` — 执行时间
- `run_count: int` — 执行次数
