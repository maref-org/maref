# E3.4 — WorkerPool

## 描述
并发任务执行工作池，支持超时熔断、优雅关闭、任务处理器注册。

## 新增文件
| 文件 | 类型 | 说明 |
|------|------|------|
| `src/maref/executor/worker.py` | NEW | WorkerPool — 并发工作池 |
| `tests/executor/test_worker.py` | NEW | 工作池测试 |

## 核心 API
- `WorkerPool(task_queue: TaskQueue, num_workers: int = 4)` — 初始化
- `start()` — 启动工作池
- `stop(timeout: float = 10.0)` — 优雅关闭
- `register_handler(name: str, handler: Callable)` — 注册任务处理器
- `submit(task: Task) -> str` — 提交任务到队列
- `get_status() -> dict` — 获取工作池状态
- `pause() / resume()` — 暂停/恢复

## Worker 行为
- 从 TaskQueue 拉取任务并执行
- 超时任务自动标记为 TIMEOUT
- 失败任务根据 max_retries 自动重试
- 超过 max_retries 移入死信队列
- 优雅关闭时等待进行中任务完成

## 断言验收
- [ ] E3.4-A1: WorkerPool 并发执行任务，不阻塞
- [ ] E3.4-A2: 超时任务被标记为 TIMEOUT
- [ ] E3.4-A3: 失败任务自动重试 (≤ max_retries)
- [ ] E3.4-A4: 优雅关闭等待进行中任务完成
- [ ] E3.4-A5: 暂停后不再消费新任务
