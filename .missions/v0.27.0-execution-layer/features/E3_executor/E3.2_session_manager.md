# E3.2 — SessionManager

## 描述
SSE/WebSocket 会话管理，支持心跳检测、会话恢复、超时管理。

## 新增文件
| 文件 | 类型 | 说明 |
|------|------|------|
| `src/maref/executor/session.py` | NEW | SessionManager — 会话管理 |
| `tests/executor/test_session.py` | NEW | 会话管理测试 |

## 核心 API
- `SessionManager(task_queue: TaskQueue, heartbeat_interval: float = 30.0)` — 初始化
- `create_session(session_id: Optional[str] = None, ttl: float = 3600.0) -> Session` — 创建会话
- `get_session(session_id: str) -> Optional[Session]` — 获取会话
- `update_heartbeat(session_id: str) -> bool` — 更新心跳
- `check_timeouts() -> list[str]` — 检查超时会话
- `close_session(session_id: str) -> bool` — 关闭会话
- `list_sessions(status: Optional[str] = None) -> list[Session]` — 列出会话
- `recover_session(session_id: str) -> Optional[Session]` — 恢复会话
- `stats() -> dict` — 统计信息

## Session 数据
- `id: str` — 会话 ID
- `status: str` — active / idle / closed / expired
- `created_at / last_heartbeat / closed_at: str` — 时间戳
- `ttl: float` — 存活时间（秒）
- `metadata: dict` — 元数据
- `task_ids: list[str]` — 关联任务 ID 列表

## 断言验收
