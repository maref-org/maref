# E3.1 — TaskQueue 持久化

## 描述
SQLite 后端实现持久化任务队列，支持优先级排序、死信队列、任务状态持久化。

## 核心 API

### TaskQueue
- `__init__(db_path: str)` — 初始化 SQLite 数据库，创建表结构
- `enqueue(task: Task) -> str` — 入队，返回 task_id
- `dequeue(limit: int = 1) -> list[Task]` — 按优先级出队
- `peek(limit: int = 1) -> list[Task]` — 预览队列头部
- `update_status(task_id: str, status: TaskStatus, **updates) -> bool` — 更新任务状态
- `get(task_id: str) -> Optional[Task]` — 获取单任务
- `list_tasks(status: Optional[TaskStatus] = None, limit: int = 100) -> list[Task]` — 查询任务
- `delete(task_id: str) -> bool` — 删除任务
- `move_to_dlq(task_id: str, reason: str) -> bool` — 移入死信队列
- `list_dlq(limit: int = 100) -> list[Task]` — 查看死信队列
- `retry_dlq(task_id: str) -> bool` — 从死信队列重试
- `stats() -> dict` — 队列统计数据
- `clear() -> int` — 清空已完成/失败/取消的任务
- `close()` — 关闭连接

### Task 类型
- `id: str` — UUID
- `name: str` — 任务名
- `priority: TaskPriority` — LOW/MEDIUM/HIGH/CRITICAL
- `status: TaskStatus` — PENDING/QUEUED/RUNNING/COMPLETED/FAILED/CANCELLED/TIMEOUT
- `payload: dict` — 任务数据
- `metadata: dict` — 元数据
- `created_at / updated_at / started_at / completed_at` — 时间戳
- `timeout_seconds: Optional[float]` — 超时时间
- `max_retries / retry_count: int` — 重试配置
- `error_message: Optional[str]` — 错误信息
- `session_id: Optional[str]` — 关联会话
- `tags: list[str]` — 标签
- `to_dict() / from_dict()` — 序列化/反序列化

## 断言验收
