# E3.3 — Checkpointer

## 描述
状态快照与故障恢复机制，支持版本管理、快照创建/恢复、完整性校验。

## 新增文件
| 文件 | 类型 | 说明 |
|------|------|------|
| `src/maref/executor/checkpointer.py` | NEW | Checkpointer — 状态快照与恢复 |
| `tests/executor/test_checkpointer.py` | NEW | 检查点测试 |

## 核心 API
- `Checkpointer(task_queue: TaskQueue, db_path: str)` — 初始化
- `create_snapshot(label: str = "") -> str` — 创建快照，返回 snapshot_id
- `restore(snapshot_id: str) -> bool` — 恢复快照
- `list_snapshots(limit: int = 100) -> list[Snapshot]` — 列出快照
- `get_snapshot(snapshot_id: str) -> Optional[Snapshot]` — 获取快照详情
- `delete_snapshot(snapshot_id: str) -> bool` — 删除快照
- `verify_integrity(snapshot_id: str) -> bool` — 校验快照完整性
- `prune(keep: int = 10) -> int` — 清理旧快照

## Snapshot 数据
- `id: str` — UUID
- `label: str` — 标签
- `created_at: str` — 创建时间
- `task_count: int` — 包含的任务数
- `status_summary: dict` — 各状态任务数量
- `checksum: str` — SHA-256 校验和
- `data: bytes` — 快照数据 (JSON serialized)

## 断言验收
- [ ] E3.3-A1: 快照创建后包含当前队列所有任务状态
- [ ] E3.3-A2: 快照恢复后队列状态与快照一致
