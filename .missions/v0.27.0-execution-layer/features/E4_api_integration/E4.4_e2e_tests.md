# E4.4 — 端到端集成测试

## 描述
全链路集成测试：API → Executor → MCP → Governance。验证 4 个端点的完整流程，包括治理层拦截、任务队列持久化、状态转换。

## 测试场景

### E2E-1: 任务生命周期
1. POST /api/v1/tasks 创建任务 → 返回 task_id
2. GET /api/v1/tasks/{task_id} 查询 → status == "queued"
3. 模拟 worker 执行 → status 变为 "running" → "completed"
4. GET /api/v1/tasks/{task_id} 确认最终状态

### E2E-2: 任务取消
1. POST 创建任务
2. POST /api/v1/tasks/{id}/cancel → status == "cancelled"
3. GET 确认状态

### E2E-3: 任务列表过滤
1. 创建多个任务
2. GET /api/v1/tasks?status=queued → 只返回 queued 任务
3. GET /api/v1/tasks?priority=3 → 只返回 CRITICAL 任务

### E2E-4: 错误处理
1. GET 不存在的任务 → 404
2. 无效 priority 值 → 422
3. 取消已完成任务 → 409
