# E4.2 — 通知通道

## 描述
抽象通知通道层，支持 Email/Webhook/CLI 三种通知方式。任务完成/失败时通过注册的通道发送通知。

## 新增文件
| 文件 | 类型 | 说明 |
|------|------|------|
| `src/maref/executor/notifications.py` | NEW | 通知通道抽象 + 3 种实现 |
| `tests/executor/test_notifications.py` | NEW | 通知通道测试 |

## 核心 API

### NotificationChannel (ABC)
- `send(title: str, message: str, level: str = "info") -> bool` — 发送通知

### EmailChannel
- 配置: smtp_host, smtp_port, username, password (env), from_addr, to_addrs
- 使用 smtplib 发送 HTML 邮件

### WebhookChannel
- 配置: url, headers, timeout
- 使用 httpx POST JSON payload

### CLINotificationChannel
- 配置: use_rich (bool)
- 使用 rich.console 或 print 输出到终端

### NotificationManager
- `register_channel(name, channel)` — 注册通道
- `notify_all(title, message, level)` — 通知所有通道
- `remove_channel(name)` — 移除通道
