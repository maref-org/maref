# E4.3 — GUI 任务面板

## 描述
React UI 组件实现任务面板，展示任务列表、状态、优先级，支持取消操作。

## 新增/修改文件
| 文件 | 类型 | 说明 |
|------|------|------|
| `gui/src/components/views/TaskPanelView.tsx` | NEW | 任务面板主组件 |
| `gui/src/api/client.ts` | MODIFY | 添加任务 API 方法 |
| `gui/src/App.tsx` | MODIFY | 添加任务路由 |
| `gui/src/components/layout/Sidebar.tsx` | MODIFY | 添加任务导航项 |
| `gui/src/types/index.ts` | MODIFY | 更新 Task 类型 |

## 组件结构

### TaskPanelView
- 任务列表（表格展示）
  - 列: ID, 名称, 状态, 优先级, 创建时间, 操作
  - 状态标签颜色: pending(灰), queued(蓝), running(绿), completed(灰), failed(红), cancelled(橙)
  - 操作: 查看详情, 取消
- 过滤栏: 按状态过滤, 搜索框
- 任务详情弹窗: 显示完整 Task 信息

### API Client 新增
- `api.submitTask(body)` — POST /api/v1/tasks
- `api.getTask(id)` — GET /api/v1/tasks/{id}
- `api.cancelTask(id)` — POST /api/v1/tasks/{id}/cancel
- `api.listTasks(params)` — GET /api/v1/tasks
