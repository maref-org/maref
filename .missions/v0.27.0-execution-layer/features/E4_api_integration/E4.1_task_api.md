# E4.1 — 任务 API 端点

## 描述
FastAPI RESTful API 用于任务提交、查询、管理。提供 4 个 REST 端点 + OpenAPI schema 自动生成。

## 新增文件
| 文件 | 类型 | 说明 |
|------|------|------|
| `src/maref/executor/api.py` | NEW | FastAPI APIRouter — 4 任务端点 |
| `tests/executor/test_api.py` | NEW | API 端点测试 |

## 核心 API

### 端点
- `POST /api/v1/tasks` — 提交任务
  - Request: `{"name", "description", "priority", "payload", "timeout_seconds", "max_retries", "tags", "session_id"}`
  - Response: `{"task_id", "status", "created_at"}`
- `GET /api/v1/tasks/{task_id}` — 获取任务状态
  - Response: Task 完整对象
- `POST /api/v1/tasks/{task_id}/cancel` — 取消任务
  - Response: `{"task_id", "status"}`
- `GET /api/v1/tasks` — 任务列表 + 过滤
  - Query: `status`, `priority`, `session_id`, `tag`, `limit`, `offset`
  - Response: `{"tasks": [...], "total"}`

### Pydantic Models
- `TaskCreate` — 创建请求体
- `TaskResponse` — 任务响应
- `TaskListResponse` — 列表响应
- `CancelResponse` — 取消响应
- `ErrorResponse` — 错误响应

### 依赖
- FastAPI (sidecar optional dependency)
- TaskQueue (E3.1)
