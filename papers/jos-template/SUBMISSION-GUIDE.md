## 二、重要注意事项

### 2.1 arXiv/Zenodo 发布的影响

**问题**: MAREF 白皮书已在 Zenodo 发布（DOI: 10.5281/zenodo.22432290），这是否算"正式出版物"？

**分析**:
- Zenodo 是预印本平台，类似 arXiv
- 国内期刊通常接受预印本后的扩展版本
- 但需要确认《软件学报》的具体政策

**建议方案**:
1. **方案 A（推荐）**: 联系编辑部确认政策
2. **方案 B**: 在投稿时说明情况，等待初审结果
3. **方案 C**: 删除 Zenodo 上的版本（不推荐）

**联系邮件模板**:
```
主题：关于预印本平台发布后投稿的咨询

尊敬的《软件学报》编辑部：

您好！我们计划投稿一篇关于多Agent系统治理框架的论文。该论文的技术白皮书已在 Zenodo 预印本平台发布（DOI: 10.5281/zenodo.22432290）。

请问：
1. 预印本平台发布是否影响投稿资格？
2. 如何在投稿时说明情况？

论文标题：MAREF：面向多Agent系统的递归演化治理框架

谢谢！
```

## 三、注册流程

### 步骤 1: 访问投稿系统

1. 打开浏览器
2. 访问 http://www.jos.org.cn
3. 点击 **"作者中心"** 或 **"在线投稿"**

### 步骤 2: 注册账号

1. 点击 **"注册"** 按钮
2. 填写注册信息：
   - **邮箱**: frankiehit@hotmail.com
   - **密码**: 设置密码
   - **姓名**: 填写真实姓名
   - **单位**: 填写工作单位
   - **电话**: 填写有效电话
3. 点击 **"提交"**
4. 查收验证邮件，完成邮箱验证

### 步骤 3: 登录系统

1. 使用注册的邮箱和密码登录
2. 进入 **"作者中心"**

## 四、投稿流程

### 步骤 1: 创建新稿件

1. 点击 **"新建投稿"** 或 **"提交新稿"**
2. 选择稿件类型：**"研究论文"**
3. 选择投稿栏目：**"软件工程"** 或 **"系统软件与软件工程"**

### 步骤 2: 填写稿件信息

#### 基本信息

| 字段 | 填写内容 |
|------|---------|
| **标题** | MAREF：面向多Agent系统的递归演化治理框架 |
| **英文标题** | MAREF: A Recursive Evolution Governance Framework for Multi-Agent Systems |
| **作者** | 填写所有作者信息 |
| **单位** | 填写所有作者单位 |
| **关键词** | 多Agent系统；Agent治理；形式化验证；国密合规；状态机；安全治理 |
| **英文关键词** | Multi-Agent Systems; Agent Governance; Formal Verification; National Cryptography Compliance; State Machine; Security Governance |

#### 稿件信息

| 字段 | 填写内容 |
|------|---------|
| **稿件类别** | 研究论文 |
| **投稿栏目** | 软件工程 |
| **基金项目** | 如有，填写基金信息 |
| **通信作者** | 选择通信作者 |

### 步骤 3: 上传文件

1. 上传 **PDF 文件**（编译生成的 `jos-sample.pdf`）
2. 上传 **LaTeX 源文件**（压缩为 ZIP）
3. 上传 **图片文件**（如有）

### 步骤 4: 预览和提交

1. 预览稿件信息
2. 确认无误后点击 **"提交"**
3. 记录 **稿件编号**

## 五、投稿后跟踪

### 5.1 状态查询

登录后在 **"作者中心"** → **"我的投稿"** 中查看状态。

### 5.2 常见状态

| 状态 | 说明 | 预计时间 |
|------|------|---------|
| **初审** | 编辑部初审 | 1-2 周 |
| **外审** | 送专家审稿 | 3-6 个月 |
| **修回** | 返回修改意见 | 1-2 个月 |
| **终审** | 编委会终审 | 1-2 周 |
| **录用** | 稿件录用 | - |

### 5.3 审稿周期

- **初审**: 1-2 周
- **外审**: 3-6 个月
- **修回**: 1-2 个月
- **终审**: 1-2 周
- **总计**: 约 5-8 个月
