# 使用 Overleaf 在线编译

## 快速开始（5 分钟）

### 步骤 1: 注册 Overleaf 账号

1. 访问 https://www.overleaf.com
2. 点击 "Sign up" 或 "注册"
3. 使用邮箱注册（可用 frankiehit@hotmail.com）
4. 验证邮箱

### 步骤 2: 创建新项目

1. 登录后点击 "New Project"
2. 选择 "Blank Project"
3. 项目名称: `MAREF-JOS`

### 步骤 3: 上传文件

将以下文件上传到 Overleaf:

| 文件 | 说明 |
|------|------|
| `jos-sample.tex` | 主文档 |
| `jos-body.tex` | 正文 |
| `jos-bib.bib` | 参考文献 |

### 步骤 4: 编译

1. 点击 "Recompile" 按钮
2. 等待编译完成
3. 下载生成的 PDF

---

## 文件下载

从本地下载文件:

```bash
# 打包文件
cd papers/jos-template
zip -r MAREF-JOS.zip jos-sample.tex jos-body.tex jos-bib.bib
```

然后将 `MAREF-JOS.zip` 上传到 Overleaf。
