# v0.47.0 R1 监管 ENFORCE 进执行 实现笔记

日期: 2026-08-03
版本: v0.47.0-dev（基线 v0.46.1）
范围: v0.47 最后一项 —— 监管强制（ENFORCE）接入执行预检

## 概述

v0.46.1 深度审计定位：**监管 ENFORCE 仅进凭证证明，未参与动作执行前校验**——
`RegulatoryPolicyMapper.map_action` 的 ENFORCE 结果不接入 `RiskAuthorizationCheck`，
且未知辖区返回宽松 OBSERVE（fail-open）画像。

本迭代把 ENFORCE 接入执行预检硬门禁，未知辖区改 fail-closed。

## 交付物

### `src/maref/compliance/jurisdiction_profile.py`

- `get_profile` 未知辖区：返回带 `enforcement_table={low/medium/high/irreversible: ENFORCE}`
  的 fail-closed 严格画像（替代宽松空表 OBSERVE）。`map_action` 对未知辖区的动作一律
  ENFORCE + blocked=True。

### `src/maref/governance/task_preflight.py`

- `RiskAuthorizationCheck.execute` 增加 `jurisdiction` context key：
  - 提供时用 `RegulatoryPolicyMapper.map_action(action, jurisdiction)` 判定 ENFORCE；
  - ENFORCE 且无授权范围 → `PreflightCheckStatus.FAIL`（fail-closed，`enforce_blocked` 标记，
    `action_required="HITL"`）——即使动作本身 LOW/MEDIUM 也不得自动放行；
  - ENFORCE 且有 scope → 正常经 TrustBoundary 裁决。

### `src/maref/identity/agent_identity_service.py`

- 模块级 `from maref.compliance.regulatory_policy_mapper import RegulatoryPolicyMapper`
  改为方法内延迟 import——消除 `identity/__init__ → agent_identity_service → regulatory_policy_mapper`
  与 `task_preflight → trust_boundary → credential → identity/__init__` 的包初始化循环
  （预先存在，R1 测试触发）。

## 设计决策

| 决策 | 理由 |
|------|------|
| 未知辖区 → ENFORCE | 监管语义下未知辖区不应默认放行（fail-open）；ENFORCE 进 TrustBoundary 强制校验 |
| ENFORCE 且无 scope → FAIL（即使 LOW/MEDIUM） | 监管强制优先于风险分级自动放行；授权范围是执行前提 |
| ENFORCE 有 scope → 正常裁决 | 有授权即满足监管门槛，剩余按风险分级 |
| `enforce_blocked` 标记 | 审计可见性（预检结果暴露监管阻断原因） |
| agent_identity_service 延迟 import | 消除预先存在的包初始化循环（R1 测试暴露） |
