# v0.34.0-rc 全量补强实现笔记

## Phase 0.1: MCP Bridge 重写

将 `mcp_bridge.py` 中 `handle_tool_call` 从占位字符串路由改为真实治理对象调用。创建 11 个 handler，分别路由到：

- `GovernanceStateMachine` — 状态机操作 (status/transition/analyze)
- `AuditLogger` — 审计日志查询
- `CircuitBreaker` — 断路器状态与控制
- `TrustEngine` — 信任评分
- `DriftDetector` — 分布漂移检测

同时创建 `opencode.json` MCP 配置，注册工具元数据。

关键模式：handler 函数式注册 + 错误统一包装为标准 MCP JSON-RPC 错误响应。

## Phase 1.1: 安全修复

P0 修复 3 项：

1. **CSP unsafe-inline** — Electron HTML 中移除 `script-src 'unsafe-inline'`，改为 nonce 方案
2. **加密算法替换** — `sm2`/`sm4_gcm` 国产算法替换为 `gmssl`/`AESGCM`（标准库优先）
3. **Cosign 死代码** — 删除未使用的 Cosign 验证死代码，消除供应链攻击面

审计日志自动捕获每次安全变更。

## Phase 1.2: 桌面 Agent 完整实现

从 1/7 stub 补全全部 7 个方法：

- `click` — 基于 pyautogui 的坐标/元素点击，支持双指/右键修饰
- `type` — 键盘输入，支持 `special_keys` 映射 (Cmd, Enter, Tab, etc.)
- `screenshot` — 全屏/区域截图，返回 base64
- `extract_text` — OCR (PIL + pyautogui) 文本提取
- `extract_links` — 基于 `extract_text` + 正则 `r'https?://[^\s]+'`
- `execute_js` — macOS AppleScript/JXA 注入，WebView 中执行 JS
- `get_ui_tree` — macOS Accessibility API (pyobjc) 获取 UI 层级树

所有方法通过 `_check_accessibility` 守卫，无权限时返回明确错误。

## 审计总线架构

创建 `governance/audit_bus.py` — 基于 `asyncio.Event` 的 pub/sub:

- `AuditBus` 单例管理订阅者列表
- `publish(event_type, data)` — 发布事件到所有匹配订阅者
- `subscribe(event_type, callback)` — 注册回调
- `unified_audit` 委托模式 — 上层调用 `unified_audit()` 自动分发到所有注册审计后端

替换原有 `MetaCircuitBreaker` 为标准 `CircuitBreaker`（统一接口，移除冗余）。

## Sidecar 打包

`packaging/` 目录创建：

- `build-sidecar.sh` — PyInstaller 构建脚本，single binary
- `verify-sidecar.sh` — 二进制验证（size/checksum/smoke test）

## 可复用的模式

1. **Handler 注册表** — MCP 工具路由采用 `{handler_name: callable}` 字典，避免 if/elif 链条
2. **测试隔离** — 外部依赖的测试标记 `xfail`，不阻塞 CI 通道
3. **委托审计** — 单一入口 `unified_audit()` 分发到多后端，消除重复
4. **Accessibility 守卫** — 桌面方法统一调用 `_check_accessibility()`，集中管理权限检查
