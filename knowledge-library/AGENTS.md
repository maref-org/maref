# Knowledge Library — MAREF v0.31.0

Temporary workspace for cross-session knowledge artifacts.

## Purpose
Store implementation notes, design decisions, and research findings
that persist across development sessions and feature branches.

## Structure
```
knowledge-library/
├── AGENTS.md           # This file: workspace metadata
├── notes/              # Free-form implementation notes
└── decisions/          # Architecture Decision Records (ADR)
```

## Rules
- Each entry must be date-stamped (YYYY-MM-DD)
- Must reference relevant feature/mission IDs
- Must not contain secrets, paths, or T3/T2 content
