# v0.47.0 F2 共识成员身份认证 实现笔记

日期: 2026-08-03
版本: v0.47.0-dev（基线 v0.46.1）
范围: v0.47 P1 联邦治理闭环第二项 —— consensus 投票绑定成员表

## 概述

v0.46.1 深度审计定位：**`FederatedConsensus` 投票不校验投票者身份**——`vote()` 接受任意
`voter_id`（非成员可投），`member_count` 只是计数无成员表。规划专项验收 F2：非成员私钥投出的
票 → 拒绝并记 `unauthorized_vote` 审计；成员票 → 正常聚合。

本迭代为 consensus 投票绑定成员表，非法成员投票拒绝。

## 交付物

### `src/maref/governance/federated_consensus.py`

- `FederatedConsensus.__init__` 新增 `membership: Any | None = None` 参数
  （鸭子类型：`members_summary()`（MembershipManager 风格）或 `member_snapshots()`
  （health_monitor 风格）均可，返回 dict 键为成员 id）。
- `vote()` 在已有校验（proposal 存在/OPEN/未过期/未重复投）后、记录投票前：
  `membership` 配置时校验 `voter_id in member_ids`，非成员 → 记
  `consensus.unauthorized_vote` 审计 + 返回 False（fail-closed）。
- 新增 `membership_enforced` 属性（是否绑定成员表）+ `_member_ids()` 解析成员 id 集合。
- `summary()` 透出 `membership_enforced`。
- 票面 `voter_id` Ed25519 签名已有（`signer` 参数 + `ConsensusVote.signature`/
  `verify_signature`），F2 复用该机制：成员私钥签发，`verify_signature` 可第三方验签。
- 未配置 `membership` → 行为不变（向后兼容，既有 consensus 测试零改动）。

## 设计决策

| 决策 | 理由 |
|------|------|
| `membership` 鸭子类型（两种方法名都支持） | `MembershipManager.members_summary` 与 `health_monitor.member_snapshots` 都可能是成员源，兼容两种 |
| 校验放重复投之后、记录之前 | 复用既有 proposal 状态校验；成员校验是身份层 |
| 非成员 → 记 `unauthorized_vote` 审计 + False | 满足专项验收「记 unauthorized_vote 审计」；fail-closed |
| 未配置 membership 向后兼容 | 既有 consensus 测试/调用零改动；生产装配 membership 即启用 |
| 复用已有 Ed25519 投票签名 | F2 的「票面 voter_id 签名」机制已实现，无需重造 |
