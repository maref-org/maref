## 2. 关键设计决策

1. **登记 vs 实际漂移**：`ExternalAccountRegistry.undeclared_accounts()` 把"使用外部身份前必须登记"作为治理语义——未登记即用 → `IDENTITY_SPOOFING` 事件，与现有 `capability_drift_detector` 的"声明 vs 实际"一致。
2. **指纹三维加权**：写作风格（字符 n-gram cosine）0.5 + 活跃时间（24h/6桶重叠）0.2 + 网络出口（IP/UA 哈希匹配）0.3。任一维度无数据 → 中性 0.5，不误拉低。
3. **Sybil 聚类**：指纹相似度图 BFS 连通分量 + 短窗口（24h 内同 agent ≥3 账号）滑动窗口 + 未声明账号，三类信号 union 后建 `SybilCluster`，置信度 = 0.5 基分 + 信号加权。
4. **共谋三检**：
   - 自导自演：背书者与被背书者同 agent_did 或同 sybil 集群（confidence 0.9/0.85）
   - 互相背书：A↔B 双向背书闭环（0.75）
   - 跨代理共享：同一 (platform, handle) 被 ≥2 个 agent 使用，或显式 SHARE 事件（发现 ④ 的"共享遗产"）
5. **关键 bug 修复**：跨代理共享最初按 `account_id` 聚合，但 registry 对同 handle 幂等去重导致检测不到"同句柄多 agent"；改为按 `(platform, handle)` 聚合。
