# v0.47.0 F4 持久化收敛 实现笔记

日期: 2026-08-03
版本: v0.47.0-dev（基线 v0.46.1）
范围: v0.47 P1 联邦治理闭环第四项 —— 联邦关键状态接入 SQLite 持久化

## 概述

v0.46.1 深度审计定位：**联邦关键状态全部纯内存**——重启后丢失（DIDRegistry/AgentDNS/
CrossOrgHITL/FederatedConsensus 状态、策略决策日志、管辖决策日志）。同时 `FederationPolicyEngine`
**根本没有决策日志字段**（评估结果即弃）。

本迭代把 6 个模块的关键状态接入 SQLite（复用 `maref.governance.db.DatabaseManager`，统一
"内存 + 可选 db_path"双分支模式，参照 `metering.py`/`settlement.py` 先例），支持重启恢复。

## 交付物（6 模块）

| 模块 | 持久化内容 | 说明 |
|------|-----------|------|
| `identity/did_registry.py` | `_agents` 记录 | `__init__(db_path)` + `_init_schema`/`_load_from_disk`/`_persist`/`_delete`；`state_machine` 经 `snapshot()`/`StateMachineSnapshot` 序列化恢复；register/revoke/deactivate/unregister 写穿 |
| `identity/agent_dns.py` | `_cards`（AgentCard） | 已有 `to_dict`/`from_dict`；`__init__(db_path)` + 写穿；register/unregister 持久化 |
| `federation/hitl.py` | `_requests`（CrossOrgApprovalRequest） | 补 `CrossOrgApprovalRequest.from_dict`；`__init__(db_path)` + 写穿；request_approval/approve/reject/process_timeouts 持久化（status 变更写穿） |
| `governance/federated_consensus.py` | `_proposals`（含完整 votes） | 扩展 `ConsensusVote.to_dict/from_dict`、`ConsensusProposal.to_dict`（补完整 votes 明细）+ `from_dict`；`__init__(db_path)` + 写穿；propose/vote/resolve 持久化（Ed25519 签名证据可恢复验签） |
| `federation/policy.py` | 规则 + conflict_strategy + **决策日志（从零新增）** | `PolicyRule.from_dict`；`__init__(db_path)`；`evaluate()` 拆 `_evaluate_impl` + 包装记录 `_record_decision` → `decision_log()`；add/remove/set_conflict_strategy 写穿 |
| `federation/jurisdiction_router.py` | `_decision_log` | `__init__(db_path)` + 写穿（`_persist_decision`）；`_record_decision` append 后写库 |

另修复：`identity/__init__` 包初始化循环（`did_registry` 的 `from maref.governance.state_machine`
eager import 触发 governance/__init__ → trust_boundary → credential → did_registry 循环）；
改为 TYPE_CHECKING + 运行时函数内 import。

## 设计决策

| 决策 | 理由 |
|------|------|
| 统一"内存 + 可选 db_path"双分支 | 与 metering/settlement 先例一致；无 db_path 时零行为变化（向后兼容） |
| 写穿式（每次变更即 persist） | 重启丢失窗口最小；查询仍走内存索引（性能） |
| 决策日志从零新增（policy） | F4 要求策略决策日志可审计；`evaluate` 包装避免改 5 个 return 点 |
| 序列化补全 votes 明细 | 保留 consensus 的 Ed25519 可验证证据（to_dict 此前只出统计数） |
| state_machine 用 snapshot 而非持久化对象 | snapshot/restore 已有序列化层，避免序列化活对象 |
| TYPE_CHECKING 修复循环 | 消除预先存在的包初始化顺序敏感缺陷 |
