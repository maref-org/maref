## 2. 关键设计决策

1. **三态裁决优先级**（`gate.py:_decide`）：
   DENY = 可执行载荷 / 凭证+代码诱饵组合 / 凭证+链接组合 / 对真人 ≥0.95 强信号
   HITL = 非阻断载荷风险 / 2+ 组合 SE 模式 / 高危渠道(文件传输/HTTP)+真人 / 联系人不可信+风险上下文
   ALLOW = 无信号 + 载荷干净
2. **隐写检测改精确匹配**：`payload.py` 不复用 `UnicodeAnomalyDetector`（其允许类别仅覆盖 Latin，会把中文 `Lo` 类误报为隐写），改为仅精确匹配 `KNOWN_STEGO_CODEPOINTS`（零宽/BOM/方向控制）。**关键 bug 修复点**。
3. **零侵入挂接**：`guard.py` 用装饰器/包装器（wrap_sender/wrap_mcp_client/wrap_a2a_client/wrap_tool），不修改 MCPClient/A2AClient/Tool 类定义，保证既有 15723 测试不回归。
4. **sentinl 事件贯通**：DENY→CRITICAL / HITL→HIGH，`AttackType.SOCIAL_ENGINEERING`，经 `ThreatGovernanceBridge` 可触发 force_halt/force_stabilize。

## 4. AISI 场景覆盖自测

| AISI 场景 | 裁决结果 |
|-----------|---------|
| 向真人发送恶意附件（文件传输服务） | DENY（attachment_executable）|
| 凭证索取+链接组合钓鱼 | DENY（组合攻击）|
| 中文正常消息 | ALLOW（无误报）|
| 高危渠道向外部真人发送 | HITL（保守人工确认）|
