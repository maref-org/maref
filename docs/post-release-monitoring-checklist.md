## 自动提醒配置

建议在 CI/CD 中配置自动提醒：

```yaml
# GitHub Actions 示例: 发布后自动创建 Issue
- name: Create post-release monitoring issue
  uses: actions/github-script@v7
  with:
    script: |
      const body = `## 发布后监控\n\n版本: ${process.env.RELEASE_VERSION}\n\n请按 checklist 完成监控:`;
      github.rest.issues.create({
        owner: context.repo.owner,
        repo: context.repo.repo,
        title: `发布后监控: ${process.env.RELEASE_VERSION}`,
        body: body,
        labels: ['release', 'monitoring']
      })
```
