# 深圳 OPC 公司注册 + 社区入驻指南

> **目标**: 零成本完成深圳 OPC 公司注册，入驻龙岗乐荟中心 OPC 社区
> **策略定位**: 先借力后补强 — 获取政府背书和资金支持
> **预计耗时**: 1-2 周
> **预计成本**: ¥0（政府免费）

---

## 一、OPC 公司注册（1 个工作日）

### 1.1 注册前准备

| 项目 | 要求 | 状态 |
|------|------|------|
| 公司名称 | 深圳市 + [字号] + 人工智能 + 有限公司 | [ ] 待确定字号 |
| 字号建议 | "递归" / "爻变" / "治元" / "智策" / 其他 | [ ] 待选择 |
| 注册地址 | 龙岗区 OPC 社区地址（入驻后提供）或挂靠地址 | [ ] 待确认 |
| 法定代表人 | 身份证原件 + 手机号 | [ ] 待确认 |
| 注册资本 | 认缴制，建议 100 万元 | [ ] 待确认 |
| 经营范围 | 见下方 | [ ] 待确认 |

**经营范围建议**：
```
人工智能应用软件开发；数据处理和存储支持服务；
信息技术咨询服务；数字文化创意软件开发；
人工智能理论与算法软件开发；信息系统集成服务
```

### 1.2 网上注册流程

**平台**: 深圳市开办企业一窗通
**URL**: https://amr.sz.gov.cn/xxgk/qt/ztlm/opcfwzq/

| 步骤 | 操作 | 耗时 |
|------|------|------|
| 1 | 访问"一窗通"平台，选择"我要开办企业" | 5 分钟 |
| 2 | 名称自主申报：输入备选字号，系统查重 | 10 分钟 |
| 3 | 填写企业基本信息（类型/地址/资本/经营范围） | 15 分钟 |
| 4 | 填写股东/法定代表人信息 | 10 分钟 |
| 5 | 电子签名（音视频双录人脸识别） | 10 分钟 |
| 6 | 提交审核 | 即时 |
| 7 | 等待审核（通常 1 个工作日） | 1 天 |
| 8 | 审核通过 → 电子营业执照生成 | 即时 |
| 9 | 选择免费邮寄纸质执照 + 4 枚公章 | 3-5 天 |

### 1.3 注册后获取

- [ ] 电子营业执照（即时）
- [ ] 纸质营业执照（邮寄，3-5 天）
- [ ] 公章 4 枚（公章、财务章、发票章、法人章）
- [ ] 统一社会信用代码

    └── arXiv 提交确认

### 2.3 与龙虾十条政策匹配分析

| 龙虾十条 | MAREF 匹配点 | 申报策略 |
|----------|-------------|---------|
| 免费部署 上游开发项目 | MAREF 可作为 上游开发项目 的 Agent 治理插件 | 强调"治理层"互补性 |
| 数据服务 50% 补贴 | MAREF 的审计日志可用于数据合规 | 强调数据治理能力 |
| 代码贡献最高 200 万 | MAREF 开源后向国际社区贡献 | 首批申报，抢占额度 |
| 数字员工应用券 40% | MAREF 的 Desktop Agent 能力 | 强调"数字员工"场景 |
| 算力补贴 3 个月免费 | MAREF 的混沌工程/红蓝对抗需要算力 | 申请测试算力 |
| 人才落户最高 10 万 | 核心开发者学历证明 | 同步申请 |
| 免费住宿最长 2 个月 | 外地开发者/创始人 | 入驻即申请 |
| 办公空间 3-7 折/免租 | 乐荟中心 1-3 年免租 | 核心利益 |

## 四、时间线

```
Day 1:  确定公司字号 → 访问"一窗通"提交名称申报

Day 3:  审核通过 → 获取电子营业执照 → 联系乐荟中心肖经理

Day 6:   提交入驻申请
Day 7-10: 等待审核 → 签署入驻协议
Day 11-14: 办理入驻 → 申请免费住宿/算力补贴
```
