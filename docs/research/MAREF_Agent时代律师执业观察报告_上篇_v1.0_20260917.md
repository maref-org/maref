# 上篇·认知：风险已就位

## 第 1 章 现象——全球律师 AI 处罚全景（2023–2026）

### 1.1 一手数据：不是新闻，是时间表

- **总量**：截至 2026-09-14，Damien Charlotin《AI Hallucination Cases》库收录 **2,041 例**，其中**律师 811 例**、自诉（pro se）当事人 1,174 例；样本跨度约 1,240 天 → **日均约 1.6 例**。
- **失败模式分类学（本报告归纳，20 案见附录 C）**：① **虚构引用**（最常见）；② **伪造引文/曲解判例**（案真命题假）；③ **虚假事实**（把编造的"人证/物证"写进材料）；④ **隐瞒/推责**（被质询后不承认）。
- **处罚阶梯（真实案例）**：

| 案件 | 法院/地 | 时间 | 结果 | 教训 |
|---|---|---|---|---|

| Crabill（纪律案） | 科罗拉多 | 2023-11-21 | **366 天停职**（留 90 天）+ 缓刑考察 | 用 AI 出错是过失，**出事后再撒谎是执业资格问题** |

## 第 2 章 现场——智能体到底是什么（盲区破除）

### 2.1 一个 Agent 任务的全程解剖（用法律语言翻译）

| 技术环节 | 法律等价物 | 风险落点 |
|---|---|---|
| 用户下派任务（prompt） | 委托事项与授权范围 | 授权不清 → 越权 |
| Agent 规划与分派子任务 | 转委托/委托链 | 转委托是否经同意 |
| 工具调用（读文件/查库/发请求） | 调查取证/信息处理行为 | 权限边界、数据范围 |
| 输出交付（文书/报告） | 工作成果 | 未经复核即对外 |
| 记忆与日志 | 工作底稿/案卷 | 有无、可否验证 |

### 2.2 四种出事方式

1. **幻觉**（= 虚假证据/虚假引证）：模型编造判例、法条、事实；
2. **伪造授权**（= 提示注入）：外部内容伪装成指令，让 Agent 越权行动（对应 GTG-1002：AI 被 role-play 成"在做防御测试"）；
3. **越权调用**：Agent 调用了委托范围外的工具或数据；
4. **数据外泄**：客户信息进入不可控的模型/服务。

**事故实证（可引用）**：
- **Anthropic GTG-1002（2025-11）**：AI 执行 **80–90%** 战术操作，role-play 伪造授权；
- **OpenAI × Hugging Face（2026-07）**：约 **1,200 个 agent** 组成 swarm、以留言板为协作渠道，检测滞后约 9–16 天（⚠️"7 万条消息""7% 成功欺骗"官方文未载，不作引用）。

### 2.3 术语对照表（节选，全量见附录 B）

| 技术词 | 法律/执业译法 |
|---|---|
| 委托链（delegation chain） | 转委托与授权范围 |
| 提示注入（prompt injection） | 伪造授权 |
| 幻觉（hallucination） | 虚假证据/虚假引证 |
| sidecar（进程外见证） | 行车记录仪：只记录，不替你驾驶 |
| 审计链/签名（Ed25519 + Merkle） | 底稿的封存与骑缝章 |
| 选择性披露（selective disclosure） | 同一卷宗，不同主体看不同页 |
| 签发（attestation） | 对"过程"作出证明，**绝不担保结果** |

> **本章落点**：你们办了二十年的案，**被告人换了个形态。**

## 第 3 章 后果——中国法条下的最坏情况

> **法规版本（已终校）**：《律师法》经 **2026-08-28 全国人大常委会修改**（主席令第八十四号），**2026-09-01 施行**。修正未改"法律责任"章实体内容，但条序调整并重新公布：**原第四十九条 → 现第五十三条（律师）；原第五十条 → 现第五十四条（律所）**。条号经"修改决定的编号锚点"推导 + 可信转载逐字比对**双重印证**；截至 2026-09-17 国家法律法规数据库官方合订本尚未上线，终校以官方重新公布文本为准。

### 3.1 第（五十三/五十四）条逐条映射（原文摘自全国人大网 2017 文本，2026 修正未改实体）

**第五十三条（原第四十九条）——律师**：情节严重者"由省、自治区、直辖市人民政府司法行政部门**吊销其律师执业证书**"。与 AI 最相关的项：

- **第（三）项**："**向司法行政部门提供虚假材料或者有其他弄虚作假行为的**"；
- **第（四）项**："**故意提供虚假证据**或者威胁、利诱他人提供虚假证据……"；
- **第（一）项**兜底："以其他不正当方式影响依法办理案件的"；
- **第二款**：**"律师因故意犯罪受到刑事处罚的，……吊销其律师执业证书。"**（无需"情节严重"）。

> 注意：非情节严重时，法定后果是"停止执业 6 个月—1 年 + 罚款≤5 万"，**并非当然吊证**。

**第五十四条（原第五十条）——律师事务所**："情节特别严重的……**吊销律师事务所执业证书**"。与 AI 最相关的项：

- **第（七）项**："向司法行政部门提供虚假材料或者有其他弄虚作假行为的"；
- **第（八）项**："**对本所律师疏于管理，造成严重后果的**"（原文提纲所指"第 50 条第(八)项"**准确无误**，现为第 54 条第(八)项）。

### 3.3 职业责任险

- 中国保险行业协会《律师执业责任保险》条款以"**因过失行为**致委托人经济损失"为承保基础——**故意/违法行为通常不在承保范围**；
- 广东省律协实行律师职业责任险统保；**但截至核验日，未检索到面向中国律师职业责任险的"AI 专项除外"公开条款**。
- **给律师的提醒**：不要假定"我买了职业责任险，AI 用错也能赔"——是否覆盖、以何种条件覆盖，须逐案向承保方书面确认。

> **本章落点**：**中国的吊销机制成熟，只等第一起 AI 案件点燃。**

## 第 4 章 工具——MAREF 与证据链（唯一技术章）

### 4.1 治理架构一页讲清

```
律师用任意 AI（ChatGPT/DeepSeek/Harvey/影子工具）
        │
        ├─ 护栏（fail-closed）：越权即拦
        ├─ sidecar（进程外见证）：记录提示词→输出→人工复核→修改→签名
        ├─ 审计链：Ed25519 签名 → Merkle 聚合 → 外部锚定
        └─ 签发：对"过程属性"出具证明（覆盖率/锚定延迟/可验证性）——绝不担保结果
铁律：采模式、不采内容；个人级数据不可见；客户端过滤器开源可审计
```

- **一句话定位**：不替你写文书的"核验记录仪"；**MAREF 签证据，人类签责任。**

### 4.2 三个现场演示（图文版，实测复现记录见附录 E）

1. **裸跑 vs 护栏跑**：同一提示词，一处无拦截、一处被 sidecar 阻断并留痕；
2. **证据包生成与离线验证**：`maref audit export` 生成自包含证据包，`maref audit verify` 离线校验（实测 935 条链完整性 **VERIFIED ✅**）；
3. **尽责留痕七项**：见第 5 章对照表。

## 第 5 章 路径——核验、留痕、签发三件套（行动清单）

### 5.1 权威规格对照表

| 规格 | 出处 | 要素 | 用途 |
|---|---|---|---|
| **AI 尽责程序义务** | **法发〔2026〕10 号 第 19 条**（2026-09-07） | 提交 AI 生成材料前**认真核实**、提交时**就 AI 辅助情况作出说明**、并**依法担责** | 律师"必须做什么" |
