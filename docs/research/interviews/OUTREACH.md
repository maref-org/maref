# 触达话术库 v1.0

> 目标不是"约到人"，而是**约到愿意讲过去 12 个月真实代价的人**。
> 铁律：**不卖、不问意愿、不超过一屏**。第一次触达的唯一任务是换来 30 分钟。

配套：目标结构 `TARGETS.md`、候选表 `CANDIDATES.md`、访谈脚本 `SCRIPT.md`、账本 `ledger.yaml`。

## 一、渠道优先级（同一席位按此顺序用）

1. **暖介绍**（前同事 / 客户 / 共同好友转介）——回复率最高，先用
2. **半熟关系**（同一行业群、会议见过、开源项目 issue 互动过）
3. **冷启动**（邮件 / 领英 / 微信陌生）——只在前两者用尽后使用

同一个候选人**只走一条渠道**，不要多路并进（会被当群发）。

## 二、触达节奏（上限 3 次，不电话突袭）

| 触点 | 时间 | 内容 | 目的 |
|---|---|---|---|
| 第 1 次 | D0 | 冷启动 / 暖介绍请求 | 说明来意，给出"可以拒绝"的出口 |
| 第 2 次 | D+3（邮件 D+4） | 跟进 1（补一句不是卖东西） | 排除"怕被推销"这一沉默原因 |
| 第 3 次 | D+10（邮件 D+12） | 跟进 2（最后一封，明确收尾） | 留下可验证的东西，不纠缠 |
| 停止 | D+10 后 | 记 `无响应`，**不再追** | 无响应本身是数据 |

## 三、五条铁律（违反则本次触达不计入证据）

1. **不介绍产品功能**，不发 PDF/白皮书/演示视频；最多一句"开源、已发布 0.55.3"。
2. **不问"你会买吗 / 有价值吗 / 有没有预算"**——这些答案没有证据价值。
3. **不超过一屏**：微信 ≤180 字；邮件 ≤200 字 + 三个 bullet。
4. **必须给拒绝出口**，且对方拒绝后**不再追问第二次**。
5. **不在触达阶段报价**；对方问价，一律回到"先了解情况，报价在访谈后"。

## 四、模板（可直接复制）

### M1 · 冷启动 · 集成商（微信 / 领英，≤180 字）

```
X 总，打扰。我在做 Agent 交付验收相关的事：把 Agent 的行为记录做成第三方能复核的形式
（开源，已发 0.55.3）。我不确定企业是否真会为它付钱，所以在做反向验证——默认预期是"没人付"。

想约你 30 分钟，只问过去 12 个月你们交付时实际遇到的一次举证麻烦：谁问的、交了什么、
花了多少人天。不演示产品，不报价。

不方便的话直接回"不用"，我就不打扰了。
```

### M2 · 冷启动 · 持证测评机构（邮件）

```
主题：请教一个测评输入的问题（Agent 行为日志能否作为证据）

您好，

我是 MAREF 的维护者（开源 Agent 治理工具，github.com/maref-org/maref）。

有一个问题只有您能回答：如果被测方提交的是「带哈希链 + 外部时间戳的 Agent 行为日志」，
你们的测评流程会把它当作证据，还是仍要求人工台账 / 截图？

想约 30 分钟请教三件事：
1) 你们现在接受的 AI 相关证据形态是什么；
2) 什么样的日志你们会直接拒收；
3) 过去 12 个月有没有因为"证据不足"退回的案例。

我不推销产品，访谈里也不提报价。如果这个问题对你们没有价值，回一句"不适用"，
我就此打住，不会再来信。
```

### M3 · 冷启动 · 受监管企业安全负责人（邮件 / 内推）

```
主题：请教一次（30 分钟）——AI 决策的举证成本

您好，

我在研究「企业向监管或内审证明 AI 决策可追责」的实际成本，不卖产品、不做演示。

想请教三个只关于过去的问题：
1) 上一次监管或内审问"这个模型/Agent 为什么这么决策"是什么时候；
2) 你们当时交出去的是什么材料；
3) 为此投入了多少人天或外部费用。

如果贵司目前没有这类要求，也请直接告诉我——这同样是有用的答案。
记录时我只写角色与数字，不写姓名与公司名；也可以先走你们的合规审批流程。
```

### M4 · 暖介绍请求（发给中间人，不是发给目标）

```
想请你帮个忙，不是转发广告。

我在做一轮反向验证：找 3 位做过政企 Agent 交付的集成商，问他们过去 12 个月在
"证明 AI 行为合规"这件事上实际花了多少钱 / 多少人天。

你能不能帮我引荐一位你觉得最可能被这事折磨过的人？我自己发消息、自己约，
不占用你的时间，也不会提你的名字做背书。
```

### M5 · 行业群 / 社区公开提问（不带产品链接）

```
请教一个具体问题：客户验收 Agent 项目时，要求证明"这个决策是模型做的、日志没被改过"，
你们一般交什么？有没有被退回过？

在做调研，不推销、不引流。愿意私聊的我来问三个过去式问题（谁问的 / 交了什么 / 花了多少）。
```

### M6 · 跟进 1（D+3）

```
补充一句，避免误会：我不是来卖东西的，也不会有第二次推销。

只想问 3 个过去式问题：谁问的、你们交了什么、花了多少人天。
这周没空就回"下周"，我下周再来；不想聊就回"不用"，我不再打扰。
```

### M7 · 跟进 2（D+10，最后一封）

```
这是最后一封，之后不再打扰。

如果这件事跟你们无关，说明我的假设可能不成立——这对我同样是有用的答案。

以后真遇到"要证明 AI 决策可追责"的场景，随时找我。我把访谈提纲公开在这里，
不需要交换任何东西：docs/research/interviews/SCRIPT.md
```

### M8 · 约到后的确认（访谈前 1 天）

```
谢谢，定在 X 月 X 日 X 点，30–40 分钟，线上。

三件事先说清楚：
1) 我不演示产品、不报价；
2) 我会问 5 个关于过去 12 个月的问题，可能涉及金额——任何一题都可以拒答；
3) 我想录音，只用于我自己整理，不外传、不写你名字；不方便我就手记。

临时有事改期完全没问题。
```

### M9 · 对方拒绝时的标准回复（只发一次）

```
明白，谢谢直接说。

只留一句可能有用的：我把"什么才算愿意付费的证据"整理成了公开口径
（L0–L3 分级），不需要回复：docs/research/interviews/EVIDENCE.md
```

### M10 · 访谈收尾的转介请求（可选，只在对方聊得开时问）

```
最后一个问题，不勉强：你认识的人里，有谁最近被"证明 AI 决策合规"这件事折腾过？
给我一个名字、或者一句"没有"，都行。
```

## 五、回复分类与动作

| 对方回复 | 动作 | 账本 signal |
|---|---|---|
| "发点资料看看" | **不发 PDF**。回一页摘要链接 + "更具体的只能在 30 分钟里讲" | `none`（未访谈） |
| "多少钱" | "先了解你们的情况，报价在访谈之后"；仍约访谈 | `none` |
| "我们已经有方案了" | 问："现在用的是什么？上一次被质疑是什么时候？"→ 仍可访谈 | 访谈后按实际填 |
| "没需求 / 不归我管" | 问一句"那你们怎么应对监管问询"；若也无 → 记 `无此痛点` 并结束 | 不入账本 |
| "先加个微信" | 记 `已触达`，D+3 走 M6；**不算信号** | `none` |
| 3 次无回复 | 记 `无响应`，停止 | 不入账本 |
| 愿意约时间 | 发 M8，进 `已约` | 访谈后填 |

> 只有**完成访谈并获 consent** 的才进 `ledger.yaml`。触达阶段的一切热度都不算证据。

## 六、禁忌清单

- ❌ 同一模板群发 / 密送多人（被识别为群发即失去可信度）
- ❌ 附件、语音条、长图、"方便电话吗"
- ❌ 承诺"能过等保 / 能过审计 / 符合 EU AI Act"
- ❌ 贬低对方现有方案（RPA、日志平台、咨询公司）
- ❌ 在对方没同意前把内容写成案例、发朋友圈、发推
- ❌ 用"帮忙填个问卷"代替访谈（匿名问卷无法追问，且样本自选）

## 七、记录规则

- 触达状态记在 `CANDIDATES.md`（只有编号、机构类型、状态、日期）。
- **姓名、手机、邮箱、微信一律不写进仓库**；需要留联系方式时放本地密码管理器。
- 每次触达只更新一行：`状态` + `最近触达日` + `下次动作`。
- 访谈完成后才写 `ledger.yaml`，并跑 `python3 scripts/interview_ledger.py --check`。
