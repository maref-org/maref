# Framework Compatibility Matrix

MAREF integrates with all major multi-agent frameworks through standard protocols.

## Framework Support

| Framework | Version | Protocol | Status |
|-----------|---------|----------|--------|
| LangGraph | >=0.1.0 | MCP | Production |
| CrewAI | >=0.30.0 | MCP | Production |
| AutoGen | >=0.2.0 | MCP | Production |
| OpenAI Agents SDK | >=1.0.0 | MCP | Production |
| Claude Code | Latest | MCP | Production |
| Cursor | Latest | MCP | Production |
| Windsurf | Latest | MCP | Production |
| Trae CN | Latest | MCP | Production |
| Dify | >=0.6.0 | MCP | Beta |
| Coze | Latest | MCP | Beta |
| GitHub Copilot | Latest | MCP | Beta |

## Protocol Support

| Protocol | Version | Status |
|----------|---------|--------|
| MCP (Model Context Protocol) | 2025-03-26 | Production |
| A2A (Agent-to-Agent) | v0.3 | Production |
| OpenTelemetry | 1.24+ | Production |

## Status Definitions

- **Production**: Tested and supported in production deployments
- **Beta**: Functional but may have edge cases under active resolution
