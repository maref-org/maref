## 节假日 / 非工作时间升级流程

### 节假日值班

| 日期 | 值班人 | 电话 | 覆盖时段 |
|------|--------|------|----------|
| | | | 全天 24h |
| | | | 全天 24h |

### 非工作时间升级规则

```
非工作时间（22:00-09:00）:
  P0: 立即通知值班工程师 → 15min 未响应 → 升级至技术负责人
  P1: 通知值班工程师 → 30min 未响应 → 升级至技术负责人
  P2: 记录事件 → 次日工作时间处理
  P3: 记录事件 → 工作日处理
```

### 节假日升级规则

```
法定节假日:
  P0: 立即通知值班工程师 + 技术负责人
  P1: 通知值班工程师 → 15min 未响应 → 升级至技术负责人
  P2/P3: 记录事件 → 节后工作日处理
```

## 紧急通知分组

### 事件通知矩阵

| 事件类型 | 必须通知 | 抄送通知 |
|----------|----------|----------|
| P0 事件 | L1 + L2 技术负责人 + L2 运维负责人 | L3 架构师 + 安全负责人 |
| P1 事件 | L1 + L2 技术负责人 | L2 运维负责人 |
| P2 事件 | L1 | L2 技术负责人 |
| P3 事件 | L1 | — |

### 通知模板

```
[紧急] P0 事件: <事件标题>
  级别: P0 (严重)
  时间: YYYY-MM-DD HH:MM UTC+8
  组件: <组件名称>
  影响: <影响描述>
  状态: 已响应 / 处理中 / 已恢复
  处理人: <姓名>
  链接: <事件链接>
```
