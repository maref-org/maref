# MAREF 事件分级与升级路径

## 事件分级定义

| 级别 | 标签 | 描述 | 示例事件 |
|------|------|------|----------|
| **P0** | 🔴 严重 | 核心服务完全不可用，数据丢失或安全漏洞 | Sidecar Down、审计日志失败、安全漏洞 |
| **P1** | 🟠 高 | 核心功能严重降级，影响用户体验 | 高延迟、内存增长、治理决策漂移 |
| **P2** | 🟡 中 | 非关键功能退化，可容忍降级 | 性能退化、非关键告警 |
| **P3** | 🔵 低 | 咨询、建议、非功能性改进 | 使用咨询、文档建议、功能咨询 |

---

## 响应时间要求（SLA）

| 级别 | 响应时间（MTTR 目标） | 确认时间 | 升级时间 | 更新频率 |
|------|----------------------|----------|----------|----------|
| P0   | ≤ 60 分钟            | ≤ 5 分钟 | 15 分钟未响应 | 每 30 分钟 |
| P1   | ≤ 4 小时             | ≤ 15 分钟 | 30 分钟未响应 | 每 1 小时 |
| P2   | ≤ 24 小时            | ≤ 1 小时 | 4 小时未响应 | 每 4 小时 |
| P3   | ≤ 72 小时            | ≤ 8 小时 | 24 小时未响应 | 每 24 小时 |

### P1 升级路径

```
P1 事件 → L1 值班工程师（30min 未响应 → 升级至 L2）
         → L2 技术/运维负责人（如 2h 未解决 → 升级至 L3）
```

### P2 升级路径

```
P2 事件 → L1 值班工程师（4h 未响应 → 升级至 L2）
```

### P3 升级路径

```
P3 事件 → L1 值班工程师（24h 未响应 → 升级至 L2）
```

## 各层级处理人/角色定义

| 层级 | 角色 | 职责 | 响应覆盖 |
|------|------|------|----------|
| **L1** | 值班工程师（On-Call） | 初步诊断、应急止损、通知升级、事件记录 | 7×24 值班制 |
| **L2** | 技术负责人 | 根因分析、修复方案、代码修复、补丁发布 | 工作日 + 电话待命 |
| **L2** | 运维负责人 | 环境恢复、扩容缩容、回滚操作、配置修复 | 工作日 + 电话待命 |
| **L3** | 架构师 | 架构决策、系统性修复方案、事后复盘主持 | 按需召集 |
| **L3** | 安全负责人 | 安全事件分析、漏洞修复、安全审计 | 按需召集 |

## 升级触发条件

### P0 升级条件

| 条件 | 动作 |
|------|------|
| P0 事件确认后 5 分钟内无人认领 | 自动通知 L1 所有成员 |
| P0 事件确认后 15 分钟内未响应 | 自动升级至 L2 技术负责人 |
| P0 事件确认后 30 分钟内未解决 | 自动升级至 L3 架构师 |
| P0 事件确认后 60 分钟内未解决 | 通知项目管理/产品负责人 |

### P1 升级条件

| 条件 | 动作 |
|------|------|
| P1 事件确认后 15 分钟内无人认领 | 自动通知 L1 所有成员 |
| P1 事件确认后 30 分钟内未响应 | 自动升级至 L2 技术负责人 |
| P1 事件确认后 2 小时内未解决 | 自动升级至 L3 架构师 |

### P2 升级条件

| 条件 | 动作 |
|------|------|
| P2 事件确认后 1 小时内无人认领 | 自动通知 L1 备班人员 |
| P2 事件确认后 4 小时内未响应 | 自动升级至 L2 技术负责人 |

### P3 升级条件

| 条件 | 动作 |
|------|------|
| P3 事件确认后 8 小时内无人认领 | 自动通知 L1 值班人员 |
| P3 事件确认后 24 小时内未响应 | 自动升级至 L2 技术负责人 |

## 事件示例与分级依据

### P0 事件

| 事件 | 分级理由 | Runbook |
|------|----------|---------|
| Sidecar Down | Agent 状态收集完全中断，治理决策无法执行 | [RB-001](runbook/rb-001-sidecar-down.md) |
| 审计日志失败 | 合规性要求无法满足，安全事件无法追溯 | [RB-004](runbook/rb-004-audit-log-failure.md) |
| 安全漏洞 | 系统安全性受到直接威胁，可能导致数据泄露 | — |

### P1 事件

| 事件 | 分级理由 | Runbook |
|------|----------|---------|
| 高延迟 | P99 API 延迟 > 500ms 持续 5 分钟 | [RB-006](runbook/rb-006-high-latency.md) |
| 内存增长 | 内存使用率持续增长 > 5%/24h | [RB-005](runbook/rb-005-memory-growth.md) |
| 治理决策漂移 | 治理输出偏离预期范围，影响 Agent 行为 | [RB-008](runbook/rb-008-governance-drift.md) |

### P2 事件

| 事件 | 分级理由 |
|------|----------|
| 性能退化 | 非关键路径延迟增加，但仍在 SLA 范围内 |
| 非关键告警 | 不影响核心功能的告警，如次要指标波动 |

### P3 事件

| 事件 | 分级理由 |
|------|----------|
| 咨询 | 功能使用咨询、最佳实践询问 |
| 建议 | 功能改进建议、文档补充请求 |
