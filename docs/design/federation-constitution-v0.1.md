## 第一章 总则

### 1.1 联邦制原则

联邦由若干**自治组织**（Member Organization）组成，各组织保留内部自治权，共同遵守本宪法与全局红线。

- **1.1.1 自治权**: 各成员组织内部事务（本地 Agent 编排、本地策略、本地信任评估）不受外部干预。
- **1.1.2 联邦义务**: 所有成员必须实现 MAREF 核心协议（联邦传输、信任报告、审计、共识投票），方可获得成员资格。
- **1.1.3 平等原则**: 每成员一票（除非组织 DID 证书声明加权，见 L4 组织 DID）。
- **1.1.4 自愿进出**: 成员可申请加入/退出；退出须完成未决审计与结算（对齐 F4 持久化）。

### 1.2 主权边界

- **1.2.1 数据主权**: 组织数据不跨组织流动，除非获得明确同意（consent）或有合规依据（对齐 R1 监管 ENFORCE）。
- **1.2.2 执行主权**: 联邦裁决仅对跨组织动作生效；组织内部动作由本地治理（v0.47 S9-S13 单 Agent 门禁）管辖。

### 1.3 互操作性

- **1.3.1 协议统一**: 跨组织调用必须走联邦 HTTP 传输（v0.47 S1 请求签名认证）。
- **1.3.2 身份统一**: 组织与 Agent 必须持有可验证 DID（`did:maref:org:*` / `did:maref:{ns}:{id}`，见 L4）。
- **1.3.3 审计统一**: 跨组织操作必须进入分布式审计总线（见 L3 MVP）。

## 第二章 全局红线（联邦层扩展）

> 以下为联邦层新增红线，**不得**削弱 Athena 系统宪法 RL-001~RL-005。

| 编号 | 联邦红线 | 语义 |
|------|---------|------|
| **FR-001** | 人类最终决策权 | 任何不可逆跨组织动作（资金/删除/外发）必须保留 HITL 路径，联邦裁决不得剥夺人类否决权 |
| **FR-002** | 数据主权 | 组织数据不得被联邦机制强制转移；跨组织数据访问必须可审计且可撤回 |
| **FR-003** | 审计透明 | 所有跨组织操作必须进入分布式审计总线，任何成员可校验其完整性 |
| **FR-004** | 共识不可伪造 | 联邦裁决必须由成员 Ed25519 签名（对齐 v0.47 F2 共识成员认证），票面不可篡改 |

## 第三章 冲突仲裁

### 3.1 仲裁机构

联邦仲裁委员会（Federation Arbitration Council）由 ≥3 个成员组织代表组成，经成员投票选举。

### 3.2 仲裁流程

1. **申诉**: 任何成员对跨组织裁决/动作提出异议（携带审计证据）；
2. **调查**: 仲裁委员会在 7 天内调取分布式审计总线证据，独立核验；
3. **裁决**: 基于审计证据与联邦红线裁定；
4. **执行**: 裁决经 2/3 多数通过后生效，受裁决组织须在 48h 内执行或申诉。

### 3.3 裁决效力

- **3.3.1 多数门槛**: 常规裁决 2/3 多数通过即生效。
- **3.3.2 红线裁决**: 涉及 FR-001~FR-004 的裁决须 3/4 超级多数。
- **3.3.3 否决权**: 人类有权对红线裁决行使最终否决（FR-001）。

## 第四章 修订机制

### 4.1 修订提案

任何成员组织可提出宪法修订提案（携带修订理由与影响分析）。

### 4.2 修订通过

- 常规修订: 3/4 超级多数；
- 红线修订: 须全体一致 + 人类最终确认（不得削弱 FR-001~FR-004）。

### 4.3 修订生效

- 修订通过后 30 天缓冲期，供成员组织评估影响与迁移；
- 缓冲期内任何成员可提出技术性反对（重新投票）。
