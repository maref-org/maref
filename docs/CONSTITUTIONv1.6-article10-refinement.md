## 第十条 外部 Code Agent 治理

凡由 Claude Code / OpenCode / Trae CN 等外部 Code Agent 在本仓库执行的操作：

1. 启动前必须阅读 AGENTS.md（宪法红线）；

5. 不得修改受 Orchestrator 保护的文件（见 AGENTS.md "Boundaries"）。

## 二、细化建议

### 2.1 新增10.1节：外部Agent决策边界

**建议内容**:
```
### 10.1 外部Agent决策边界

外部Agent的自主决策必须满足：
- **决策范围**: 仅限技术实现决策，不得涉及治理决策
- **克隆限制**: Agent克隆须经宪法审查（RL-004）
- **跨域限制**: 跨域调用须通过TrustBoundaryManager授权
- **审计要求**: 所有决策必须有审计追踪（RL-003）
```

### 2.2 新增10.2节：Agent自主决策宪法限制

**建议内容**:
```
### 10.2 Agent自主决策宪法限制

Agent自主决策不得：
- 修改宪法红线（RL-001）
- 禁用安全门（RL-002）
- 跳过审计追踪（RL-003）
- 单方面克隆自身（RL-004）
- 修改信任权重（RL-005）
- 修改安全维度权重（RL-006）
- 超过文件限制（RL-007）
```

### 2.3 新增10.3节：外部Agent审查标准

**建议内容**:
```
### 10.3 外部Agent审查标准

外部Agent克隆审查须满足：
- **技术能力**: Agent必须具备所需技术能力
- **安全意识**: Agent必须了解宪法红线
- **审计能力**: Agent必须能够生成审计记录
- **责任能力**: Agent必须能够承担责任
```
