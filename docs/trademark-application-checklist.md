## 三、网上申请流程（1小时）

### 3.1 注册账号

1. 访问 https://sbj.cnipa.gov.cn
2. 点击"网上申请" → "用户注册"
3. 选择"申请注册"类型
4. 填写申请人信息，上传身份证明
5. 等待审核（通常1-3个工作日）

### 3.2 提交申请

1. 登录商标网上申请系统
2. 选择"商标注册申请"
3. 填写申请信息：
   - 申请人名称
   - 联系地址
   - 商标类型（文字/图形/组合）
   - 商标图样上传
4. 选择商品/服务类别（第9类 + 第42类）
5. 确认申请信息
6. 在线支付官费（¥540 = 270元/类 × 2类）
7. 提交申请，获取申请号

### 3.3 申请后跟踪

| 时间节点 | 事项 | 验证方法 |
|----------|------|----------|
| 提交后1-3天 | 收到电子受理通知书 | 邮箱查收 |
| 提交后1-2个月 | 形式审查 | 商标网查询状态 |
| 提交后6-9个月 | 实质审查 | 商标网查询状态 |
| 审查通过后 | 3个月公告期 | 商标公告查询 |
| 公告无异议 | 颁发商标注册证 | 邮寄或电子证书 |

```

```

### 4.3 GitHub 组织注册

在商标申请提交后，立即注册 GitHub 组织：

5. 验证域名（如有）
