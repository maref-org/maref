# v0.55.3 发布记录

**发布日期**：2026-11-21 ｜ **基线**：v0.55.2（2026-11-01）

> 主题：**让已发布的产物对得起 README**。v0.55.2 的 wheel 在干净环境里装完起不来，
> "可验证审计链"的命令跑不动，主产品（AG-Conformance）没有发布。本版只修发布面，不加功能。

## 为什么发这一版

2026-11-21 的产物层实测（干净 venv + PyPI 0.55.2）发现三个"装完就坏"的问题：

```bash
$ python3 -m venv /tmp/s && /tmp/s/bin/pip install maref==0.55.2
$ /tmp/s/bin/maref --version
ModuleNotFoundError: No module named 'gmssl'
$ /tmp/s/bin/pip install "maref[all]==0.55.2" && /tmp/s/bin/maref --version
ModuleNotFoundError: No module named 'gmssl'      # [all] 不是并集
```

以及：

```bash
$ maref audit verify -f empty.jsonl
│ Total entries    │ 0      │
│ Integrity intact │ ✅ Yes │   # 空文件也报"完整"，exit 0
```

## 修复

- **base 安装可运行**：`gmssl`、`cryptography` 移入 base 依赖（`maref.crypto` 在包导入期加载
  SM2/SM3/SM4，审计链 Ed25519 与 `a2a_secure_transport` 运行时需要 `cryptography`）。
- **`[all]` 是并集**：补 `identity` / `a2a` / `orchestration` / `otel`。
- **可选 extra 不再拖垮 CLI**：`maref.integration` 对 FastAPI（`[sidecar]`）改为可选导入 + 占位函数。
- **版本单一事实源**：`maref_lite.__version__` 取自 `maref.__version__`（此前硬编码 0.55.0）。
- **验签 fail-closed**：`maref audit verify` 解析 0 条时 exit 1 + `❌ No`，不再报"完整"。
- **审计路径语义**：`.governance/x.jsonl` 不再被二次前缀化为 `.governance/.governance/x.jsonl`；
  CLI 会打印 `Resolved: <真实路径>`。
- **文档入口**：`pip install maref-lite`（PyPI 404）改为 `pip install maref` / `maref[all]`；
  `@maref/sdk` 改为真实包名 `@maref-org/sdk`。

## 新增

- **AG-Conformance v0.1**：10 条控制项、stdlib-only、可对任意 runtime 导出的 trace 运行并出签名报告
  （`python3 scripts/conformance_run.py --demo good|bad`）。此前只存在于开发仓。
- **claim ledger 公开**：`claims.yaml`（10 条）每条挂可复算命令，CI 阻断漂移；
  `docs/claims.md` 为生成物（禁止手改）。
- **STATE 发布窗口语义**：`project.pending_release`，发布进行中 C1 只告警；
  发布后必须把 `current_release` 提升为目标版本并删除该字段。
- 声称门禁在 PR / main push 上**阻断**（原先默认影子模式）。

## 升级

```bash
pip install -U maref            # 或 pip install -U "maref[all]"
maref --version                 # → MAREF v0.55.3
maref audit verify -f <log> -k <pubkey.pem>
```

无需代码改动。若你在此前版本里绕过 `gmssl` 手工装过依赖，可移除。

## 已知

- `maref audit verify` 对含被篡改条目的日志会正确判定 `❌ No`（3 条中 2 条有效、1 条篡改），
  但若传入的裸文件名不在沙箱目录内，只会得到"not found"——请使用解析后的路径
  （CLI 现在会打印 `Resolved:`）。
- `STATE.yaml` 在发布完成后需更新 `current_release`；`CITATION.cff` 已随本版对齐到 0.55.3。
