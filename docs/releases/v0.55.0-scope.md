## 3. 纳入范围

1. 分支保护（required status checks）与漂移检测。
2. 发布流水线 preflight：tag 发布必须绑定全绿的 check-runs。
3. SCA：基于 `uv.lock` + 干净环境的 `pip-audit`，例外台账带到期日。
4. 覆盖率：CI 上传 artifact；`STATE.yaml` 覆盖率声明改为可复核指针。
5. D1 预检：G1/G2/G3 改为 live API 查询，不再读取 STATE 布尔。
6. 运行时证言：签名 + 新鲜度 + 公钥固定，替代恒 skipped 的占位 job。
7. meta 语义修正：M0 存活率、M1 扫描上限、M2 告警消失、M4 guard 覆盖率。
8. 审计链隔离：状态机遗留日志归档并写入签名 `chain_rebaseline` 事件。
9. `STATE.yaml` 证据指针化与 v0.54.3 记录纠偏。

## 5. 发布事实边界（发布说明必须遵守）

- 若桌面产物缺失，发布说明**不得**出现“桌面版已发布/可下载”表述。
- 若 SCA 例外未过期但存在例外，发布说明必须列出例外数量与最早到期日。
- 若覆盖率来自单一 artifact，发布说明必须附 run ID 与采集时间。
- v0.54.3 的历史记录需在 `STATE.yaml` 标注：发布 run `39404406985` 为 failure，桌面 0/4，仅产出 wheel + sdist。
