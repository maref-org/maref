# v0.55.1 发布记录

> 状态：已发布（2026-10-30，PyPI + GitHub Release）
> 成熟度：Experimental
> 分发形态：Python-only（wheel + sdist）

## 1. 发布范围

v0.55.0 之后的补丁版，收纳已合入 main 的治理内核与修复，不含架构重构：

1. 治理内核接线（#466）：`GovernedPipeline` 默认装配破坏性操作门、预算熔断器与 kill switch；入口闸（身份/委托链/入向消毒）与模型闸默认关闭，通过构造参数或 `MAREF_ENTRY_GATE` / `MAREF_MODEL_GATE` 显式启用。
2. 审计外部锚定（#466）：`AuditAnchor` 与 `scripts/verify_audit_anchor.py`，支持批次 Merkle 锚点、Ed25519 签名与离线校验。
3. 审计记录落盘 `layer` 字段并修复链尾回退（#494）。
4. 移除无测量依据的「97% 自动化率」表述（#493）。
5. 深水区登记表移出公开仓，模板路径占位符化（#495）。
6. PyPI 元数据：新增 `[project.urls]` 6 条项目链接。

明确排除：Tauri 桌面产物、容器镜像发布、依赖大版本升级（含 Rust `zip` 4.x → 9.x）。

### 兼容性影响（相对 v0.55.0）

- 破坏性操作门：命中破坏性模式时升级 HITL 或 `DENY`。
- 预算熔断：默认 `MAREF_BUDGET_MAX_PER_AGENT=1000`、`MAREF_BUDGET_MAX_PER_TASK=200`、`MAREF_BUDGET_MAX_BURN_RATE=100`。
- kill switch：仅在显式 `engage()` 后阻断对应作用域。
- 回滚：注入禁用的 gate 实例并恢复预算阈值即可回到 v0.55.0 行为。

## 4. 已知问题

1. Rust `zip` 4.6.1（`gui/src-tauri/Cargo.lock`）存在 CRITICAL `CVE-2026-115905` / HIGH `CVE-2026-115909`；仅位于桌面依赖链，不进入 PyPI/Docker 运行时。修复版本为 zip ≥ 9.0.5（跨大版本），待 Tauri 生态整体升级，已登记 `.trivyignore` 并附失效条件。
2. brotli 1.2.0 受 mitmproxy 12.3.0 硬 pin（`GHSA-9v8h-qqgm-4m35` / `CVE-2026-111497`）；Dockerfile/Dockerfile.sidecar 在安装后强制 `brotli>=1.2.1`，镜像内实际为 1.2.1。
3. `scripts/sync_version.py` 于本版本补齐 `pyproject.toml`、`src/maref/__init__.py`、`uv.lock`、`STATE.yaml` 四个版本位点；此前需手工同步，是本次发布的主要返工来源。
