# v0.55.4 发布记录

**发布日期**：2026-11-22 ｜ **基线**：v0.55.3（2026-11-21）

> 主题：**把复盘修的东西送到用户手里**。v0.55.3 修好了"装得上"，但主产品（AG-Conformance）
> 只有 git clone 能用、对外数字里仍有无来源的旧值、验签把"空"与"篡改"压成同一个结论。
> 本版把这三项搬到 PyPI 产物上，并把 sdist 从 36.9 MB 压到 8.1 MB。

## 为什么发这一版

2026-11-21 的复盘（`MAREF-任务复盘-review-20261121.md`）对已发布 0.55.3 的复核结论：

```bash
$ pip install maref==0.55.3 && maref conformance --demo good
Error: No such command 'conformance'.        # 尺子只在仓库里，pip 用户拿不到
$ grep -n "15,387\|~87%" README.md
18: ... 15,387 passing tests (CI, main@0f0c7632)
75: ... ~87% test coverage                   # 与 STATE 的 76.5% 不一致
$ maref audit verify -f empty.jsonl
FAILED: ... (empty, unreadable, or truncated by tampering)   # 空文件与篡改同一结论
```

## 新增

- **`maref conformance`**：AG-Conformance 随 wheel 发布，不再需要 clone 仓库。
  ```bash
  maref conformance --demo good            # VERDICT conformant | 10 pass / 0 fail
  maref conformance --demo bad             # exit 1（fail-closed）
  maref conformance --demo good --key "$KEY" --out /tmp/report.json
  maref conformance --verify /tmp/report.json --key "$KEY"
  ```
  支持 `--trace` 评估任意 runtime 导出的 JSONL、`--md` 输出人读报告、`--export-trace` 导出 fixture。

## 变更

- **`maref audit verify` 退出码分层**（行为变更，脚本需注意）：
  `0` 完好 / `1` 篡改或不可验证 / `2` 输入不可用（文件不存在、空日志、行不是 JSON 对象）。
  空日志现在报 `EMPTY`、格式错误报 `UNREADABLE`，不再计成 `tampered`。
  详见 `VERIFY.md` 的退出码表。
- **对外数字收敛**：README 的 `15,387 passing tests` 与 `~87% test coverage` 移除，
  改为 `16,000+ test functions`（附复算命令）与 `76.5%`（绑定 `STATE.yaml` 的 2026-11-03 工件）。
  `claims.yaml` 从 10 条增至 13 条；`docs/claims.md` 由 `claims.py --check-docs` 在 CI 强制同步。
- **sdist 瘦身**：排除 `website/public/videos`（28.2 MB）与 `sbom.spdx.json`，36.9 MB → 8.1 MB。
  新增 `scripts/verify_artifacts.py`：CI 构建后断言 wheel 的 `[all]` 并集、conformance CLI、
  base 依赖与 entry_points，以及 sdist 不携带视频。
- **访谈账本 PII 收紧**：递归扫描任意层级键与自由文本中的手机号/邮箱/微信号，`schema` 仅接受 1。

## 安装与验证

```bash
pip install maref==0.55.4
maref --version                 # MAREF v0.55.4
maref conformance --demo good   # VERDICT conformant | 10 pass / 0 fail
maref audit verify -f <empty>   # EMPTY + exit 2
python -c "from maref.conformance import run, build_trace; print(run(build_trace(compliant=True)).verdict)"
```

升级全部可选依赖：`pip install "maref[all]==0.55.4"`。

## 兼容性

- `maref audit verify` 的退出码从"0/1"变为"0/1/2"。如果你的脚本用 `!= 0` 判失败，无需改动；
  若依赖 `exit 1` 表示"任何问题"，需要区分 `2`（输入不可用）与 `1`（验证失败）。
- `maref conformance` 为新增命令，不改变既有命令。

## 已知限制（不在本版范围）

- `gate-rust-audit` 仍因 `Cargo.lock` 的 2 个 unmaintained/漏洞 crate 失败（pre-existing，非必需 check）。
- npm `@maref-org/sdk` 仍为 0.2.0（版本独立于 Python 包）。
- 真实用户验证仍为 0（0 访谈 / 0 标书 / 0 报价单）——本版不能改变这一项。
